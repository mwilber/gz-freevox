# FreeVox

FreeVox is a minimal authenticated Progressive Web App for sending input to SELMA. It has two user-facing actions:

- Send typed text to SELMA.
- Start an OpenAI realtime voice conversation, collect the completed user and assistant transcript turns, and send the final transcript to SELMA when End Conversation is pressed.

It intentionally does not show SID links, conversation history, SELMA run history, or an archive UI.

## Requirements

- Node.js 20 or newer.
- A SELMA deployment that accepts `POST /api/agent-runs`.
- An OpenAI API key with access to the selected realtime and transcription models.
- Heroku CLI for deployment.

No third-party npm packages are used.

## Configuration

Required environment variables:

- `FREEVOX_SESSION_SECRET`: long random string used to sign session cookies.
- `FREEVOX_UI_USERNAME`: the single login username.
- `FREEVOX_UI_PASSWORD_HASH`: PBKDF2 password hash generated by this app.
- `SELMA_BASE_URL`: SELMA base URL, for example `https://your-selma-app.herokuapp.com`.
- `SELMA_API_TOKEN`: bearer token sent to SELMA.
- `OPENAI_API_KEY`: server-side OpenAI API key. This is never sent to the browser.
- `REALTIME_MODEL`: OpenAI realtime speech model to use.
- `REALTIME_TRANSCRIPTION_MODEL`: OpenAI realtime transcription model to use for user speech.

Optional environment variables:

- `FREEVOX_ALLOWED_ORIGIN`: exact browser origin allowed for authenticated POSTs, for example `https://freevox.example.com`.
- `LOG_LEVEL`: set to `debug` for server-side error stack logging. Do not use this to log transcripts.

Generate the UI password hash:

```sh
npm run hash-password -- "your password"
```

Use the printed `pbkdf2$...` value as `FREEVOX_UI_PASSWORD_HASH`.

## Local Setup

Install dependencies:

```sh
npm install
```

Create a local environment file:

```sh
cp .env.example .env
```

Edit `.env` and populate the values. Generate the password hash first if needed:

```sh
npm run hash-password -- "your password"
```

Start the local server:

```sh
npm run local
```

`npm run local` loads `.env` with dotenv and listens on `PORT`, which defaults to `3000` in `.env.example`. Open `http://localhost:3000`.

Verify health:

```sh
curl http://localhost:3000/healthz
```

Expected response:

```json
{"ok":true}
```

Run automated tests:

```sh
npm test
```

## Heroku Deployment

Create the app if needed:

```sh
heroku create freevox
```

Set config vars:

```sh
heroku config:set FREEVOX_SESSION_SECRET="replace-with-a-long-random-secret"
heroku config:set FREEVOX_UI_USERNAME="mwilber"
heroku config:set FREEVOX_UI_PASSWORD_HASH="pbkdf2$sha256$..."
heroku config:set SELMA_BASE_URL="https://your-selma-host"
heroku config:set SELMA_API_TOKEN="replace-with-selma-token"
heroku config:set OPENAI_API_KEY="replace-with-openai-key"
heroku config:set REALTIME_MODEL="replace-with-realtime-model"
heroku config:set REALTIME_TRANSCRIPTION_MODEL="replace-with-transcription-model"
heroku config:set FREEVOX_ALLOWED_ORIGIN="https://freevox.herokuapp.com"
```

Deploy:

```sh
git push heroku main
```

Heroku runs the app with:

```Procfile
web: npm start
```

Verify health after deployment:

```sh
curl https://freevox.herokuapp.com/healthz
```

## PWA Installation

On Android Chrome:

1. Open the deployed FreeVox URL.
2. Sign in.
3. Open the browser menu.
4. Choose Install app or Add to Home screen.
5. Launch FreeVox from the installed home-screen icon.

The manifest includes standalone display mode, theme/background colors, 192px and 512px icons, and a maskable 512px icon. The service worker caches only the app shell and does not cache API responses, realtime credentials, text submissions, SELMA responses, or transcripts.

## Android Share Target

FreeVox registers as an Android share target for installed PWAs in Chrome. Sharing text, a title, or a URL to FreeVox opens the app and places the shared content into the text input. It does not send automatically; press Send after reviewing the text.

The manifest entry is:

```json
"share_target": {
  "action": "/share",
  "method": "GET",
  "params": {
    "title": "title",
    "text": "text",
    "url": "url"
  }
}
```

After adding or changing `share_target`, Android usually needs the PWA to be reinstalled before it appears in the OS share sheet.

To uninstall/reinstall on Android 12 with Chrome:

1. Long-press the installed FreeVox home-screen icon.
2. Tap App info or Remove.
3. Choose Uninstall, or remove the installed app if Android presents that wording.
4. Open Chrome and visit the deployed FreeVox URL.
5. Open Chrome menu.
6. Tap Install app or Add to Home screen.
7. Launch FreeVox once from the installed icon and sign in.
8. In another app, share text or a URL and choose FreeVox from the Android share sheet.

## Manual Realtime Verification

1. Sign in on the target mobile browser.
2. Press Start Conversation.
3. Grant microphone permission.
4. Confirm the status changes to Conversation active.
5. Speak a request and allow the assistant to respond.
6. Confirm the live transcript shows completed User and Assistant turns.
7. Press End Conversation.
8. Confirm the status changes to Sent.
9. Confirm SELMA received a request with `source: "freevox_realtime"`.
10. Deny microphone permission in browser settings and confirm Start Conversation reports the permission failure without sending an empty transcript.

Realtime transcript capture uses these OpenAI realtime server events:

- `conversation.item.input_audio_transcription.completed` for user speech.
- `response.output_audio_transcript.done` for assistant speech.

FreeVox keeps active voice transcript turns only in browser memory and clears them after successful submission.

## API Summary

Authenticated browser routes use signed session cookies and require `X-CSRF-Token` on POST requests.

- `POST /api/send-text`: accepts `{ "text": "..." }` and sends it to SELMA with `source: "freevox_text"`.
- `POST /api/realtime/session`: creates an OpenAI realtime client secret with the server-side OpenAI key and returns only short-lived browser-safe credential data.
- `POST /api/send-voice-transcript`: accepts completed transcript turns and sends them to SELMA with `source: "freevox_realtime"`.
- `GET /healthz`: unauthenticated health check.
